# Omarchy on Lucy

Lucy runs the [Omarchy](https://omarchy.org) desktop (Hyprland + Quickshell)
using only the **package** from [nixarchy](https://github.com/olafkfreund/nixarchy):
the upstream Omarchy tree, patched for NixOS. nixarchy's NixOS and Home Manager
modules are deliberately **not** imported.

| Piece | Where |
| --- | --- |
| Flake input (pinned tag, no `follows`, so builds hit `nixarchy.cachix.org`) | `flake.nix` → `nixarchy` |
| System side: session, greetd, fonts, PAM, desktop services | `modules/internal/nixos/desktop/omarchy.nix` (`hrndz.desktop.omarchy`) |
| User side: bindings, autostart, menu, seeded config, first theme | `modules/internal/home/desktop/omarchy.nix` |
| Lucy's settings | `hosts/x86_64-nixos/Lucy/config/desktop.nix` |

## Installing apps

Apps are **not** installed from Omarchy's menu. They come from this flake, the
same way as on every other host: roles (`hrndz.roles.*`), tooling
(`hrndz.tooling.*`), `environment.systemPackages`, `home.packages`, or the
browser/flatpak modules.

The menu's **Install**, **Remove**, **Update → Channel** and **Update → Config**
rows are hidden (`~/.config/omarchy/extensions/omarchy-menu.jsonc`). They
assume either pacman or nixarchy's installer:

- nixarchy's installer writes picks to `~/.config/nixarchy/apps.nix`, and then
  `nixarchy-apply` **copies those files into the flake** (at the repo root,
  because our host directory is `hosts/x86_64-nixos/Lucy`, not `hosts/Lucy`),
  runs `git add` on them, and switches with `nh`. That would leave generated,
  machine-specific files in this repo that you would have to commit from Lucy.
  This setup avoids it.

**Update → Omarchy** (`omarchy update`) still works. It rebuilds with
`nh os switch` from `$NIXARCHY_FLAKE` (`~/src/me/nixcfg`). It does not pull or
update inputs, so run `git pull` / `just update` first.

## Themes and plugins

These stay imperative, as upstream designed them:

- `Style` menu / `omarchy theme set <name>`: the choice is written to
  `~/.local/state/omarchy/current/`. `hrndz.desktop.omarchy.theme` only picks
  the **first-login** theme.
- `omarchy plugin add <git-url>` clones into `~/.config/omarchy/plugins/`.

Ghostty on Lucy follows the Omarchy theme through an optional
`config-file = ?~/.local/state/omarchy/current/theme/ghostty.conf` include. The
Mac hosts keep `noctis-lux`.

## Keybindings

Omarchy's `hyprland.lua` loads its defaults, then `~/.config/hypr/bindings.lua`,
which is generated by Nix. Our bindings are added **on top of** Omarchy's. Where
a key clashes, it is `hl.unbind`-ed first and ours wins:

| Key | Ours (wins) | Omarchy default it replaces |
| --- | --- | --- |
| `Super+L` | Lock (`omarchy-system-lock`) | Toggle workspace layout |
| `Alt+Tab` | Previous workspace | Next window |
| `Alt+Shift+Tab` | Move workspace to next monitor | Previous window |

Clashes where Omarchy's binding is kept: `Super+Return` (terminal, which is
Ghostty via `~/.config/xdg-terminals.list`), `Super+Space` (Omarchy menu),
`Super+F` (fullscreen), `Super+V` (universal paste), `Super+Shift+Space`
(toggle bar) and `Print` (screenshot).

Added with no clash (AeroSpace parity, where Meh = `Ctrl+Shift+Alt` and
Hyper = `Super+Ctrl+Shift+Alt`):

- Meh+H/J/K/L: focus.
- Hyper+H/J/K/L: move (swap) the window.
- Meh+`-`/`=`: resize.
- Meh+`/`: toggle split. Meh+`,`: swap split.
- Meh+W/A/R/S/T/V/C/B/D/F: named workspaces. Hyper+the same letter moves the
  window there.
- `Super+Q`: close. `Super+M`: exit the session.

To see everything that is bound: `omarchy menu keybindings --print`.

## Files that are seeded, not managed

Omarchy's tools edit these files, so they are copied in once as real files and
never overwritten: `~/.config/{omarchy,hypr,btop,imv,hyprland-preview-share-picker}`
(everything except the Nix-managed `hypr/bindings.lua`, `hypr/autostart.lua` and
the menu extension), plus `~/.config/xdg-terminals.list`. To reset one, delete it
and switch again.

## Login and remote access

greetd autologs into the Omarchy session. The session locks itself immediately:
it retries the Quickshell lock until the shell is up, and falls back to
`hyprlock` if the shell never answers. WayVNC listens on `127.0.0.1:5900`
(`hrndz.desktop.omarchy.remote`), so reach it through an SSH tunnel.

## Rolling back

Revert the commit and switch, or boot the previous generation.
